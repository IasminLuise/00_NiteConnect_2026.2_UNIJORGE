# B05.0.3 — licença e operação não aprovadas

Gate E **NOT-RUN**, conforme parada obrigatória em B2. A imagem Community já
fixada foi usada somente no laboratório autorizado. Não houve aquisição,
contratação, aceite institucional, remoção de branding ou consulta a fornecedor.

Direitos de integração/distribuição, AGPL, marca, conexões, edição móvel, suporte,
SLA e requisitos comerciais não foram revalidados nesta etapa. A existência da
Docs API instalada não concede esses direitos. Os pontos históricos continuam
pendentes e não são aprovação jurídica. A consulta formal e a capacidade
operacional seriam obrigatórias antes de selecionar qualquer solução.

G1 operacional permanece aberto: TLS/WSS, autorização institucional por contexto,
gestão/rotação de segredos, logs privados do motor, backup/restore completo,
retention, concorrência, monitoramento, disponibilidade e custos reais. Os
limites 4 GiB/2 CPUs são configuração do ensaio, não dimensionamento institucional.
Nenhum banco externo, Entra, API principal ou produção foi alterado.
