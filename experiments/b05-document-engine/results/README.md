# Evidências B05

`generated/` é ignorado: conversões sintéticas, hashes, capturas e medições locais.
Somente relatórios agregados revisados devem ser versionados. Não versionar tokens,
URLs com access_token, HAR, traces, logs brutos do Collabora ou documentos privados.

Para cada execução registrar commit-base, imagens/digests, Java/CODE/LibreOffice,
pacotes/fontes, máquina e limites Docker; fixtures e hashes; versões exatas de origem;
passos/resultado, latência e recursos; diferenças visuais e classificação de falhas.
Hash diferente de PDF não prova diferença de layout. Inspecionar páginas renderizadas.

Matriz P01–P20 e decisão ficam em ADR-B05-001.md. `PENDENTE` não equivale a aprovado.
